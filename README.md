# PARLADOR

Адаптивный сайт московского underground techno-проекта. Редизайн повторяет композицию предоставленного референса: двухстрочный логотип, тёмный склад с красным светом, горизонтальный тикер, карточки артистов, NO RULES и три колонки EVENT.

## Локальный просмотр

Откройте `index.html` в современном браузере. Сборка, npm и внешние сервисы не требуются. CSS, JavaScript, изображения и шрифты находятся в репозитории.

## Поведение

- ENTER переводит к EVENT, навигация плавно прокручивает страницу.
- Семь артистов находятся в горизонтальной полосе. На широком экране видны четыре карточки; остальные доступны кнопками, клавишами ← / → при фокусе на полосе и горизонтальной прокруткой. На iPhone видны две карточки.
- Мобильное меню работает также на широком экране; Escape закрывает его и возвращает фокус кнопке.
- Таймер считает до **19 декабря 2026, 22:00 МСК** (`2026-12-19T22:00:00+03:00`). Завершение: **20 декабря, 06:00 МСК**. После начала отрицательных значений нет.
- GET TICKETS открывает демонстрационный диалог COMING SOON. Цены, платёжные формы и ссылки продажи отсутствуют.
- Декоративная анимация отключается при `prefers-reduced-motion: reduce`.

## Контент и изображения

Артисты: DJ KALASHNIKOV, DANJAMIN, M.E.G, FRDM, ACID BOSS, Девиантный Диалект, DJ ALWEN.

`assets/warehouse.png` — отдельное сгенерированное изображение индустриального помещения без текста, логотипов и интерфейса. Это атмосферная иллюстрация, а не фотография площадки Fabula или артистов. Весь текст, карточки, таймер и кнопки — HTML-элементы. Скриншот-референс не встроен в сайт.

Archivo Black, Oswald и Anton сохранены локально. Лицензии SIL Open Font License включены в `assets/`.

## GitHub и публикация

Файлы готовы для GitHub и статического хостинга. Автоматической публикации и workflow деплоя нет. Изменения подготовлены локально; push и публикация требуют подтверждения пользователя.

## Проверки

Проверены синтаксис JavaScript, разбор CSS, локальные ресурсы, все якоря, таймер до начала/во время/после события (также при системном часовом поясе Pacific/Honolulu), меню с Escape и Tab, переключение карточек, демо билетов и возврат фокуса. Интерактивные сценарии выполнены в jsdom с заглушками геометрии, прокрутки и нативного dialog.

Ширины длинных названий и логотипа дополнительно сверены по метрикам локальных шрифтов для экранов 320–430, 1101, 1200, 1512 и 1680 px. Настоящий браузер недоступен в текущей среде: визуальная проверка Safari/iPhone/MacBook, scroll-snap и нативного модального окна остаётся перед публикацией.
