# PARLADOR — Phase 3

Статический сайт, совместимый с GitHub Pages. Сборка и сервер не требуются: откройте `index.html` или используйте статический сервер. Ресурсы и ссылки относительные, поэтому сайт работает и в подкаталоге репозитория.

Сохранены семь артистов и их порядок: KALASHNIKOV, DANJAMIN, M.E.G, FRDM, ACID BOSS, Девиантный Диалект, ALWEN. Карточки остаются контентом: без биографий, жанров, фотографий, музыкальных ссылок, модальных окон и фиктивных действий. `data-artist-id` задаёт стабильные ключи для будущих профилей; `artistProfiles` зарезервирован в конфигурации, UI профилей пока не создаётся.

Подтверждённое время события не изменено: 19 декабря 2026, 22:00 МСК — 20 декабря, 06:00 МСК. Расписание выступлений отдельных артистов не добавлено.

## Настройка билетов и Telegram

Все публичные настройки находятся в `site-config.js`, который загружается перед `script.js`. Не храните здесь секреты или персональные данные.

- `tickets.platformUrl: null`: BUY TICKET отключена; цены показываются как анонсированные по расписанию. Для открытия продаж укажите проверенную HTTPS-ссылку реальной билетной платформы. Покупка откроется на этой платформе в новой вкладке. Сайт не принимает платежи.
- `tickets.stages`: пять подтверждённых этапов с ценами, ISO-датами начала и исключающего конца; `timeZone: Europe/Moscow`, `currency: RUB`.
- `community.telegramUrl: null`: JOIN TELEGRAM отключена. Укажите подтверждённую HTTPS-ссылку канала на `t.me` или `telegram.me`. Пока ссылки нет, переходов нет.
- Неверные, относительные, HTTP- и `javascript:`-ссылки не активируют кнопки. Код проверяет формат URL; подлинность платформы и канала необходимо подтвердить владельцу перед заполнением конфигурации.
- `newsletter: { enabled: false, provider: null }` — точка расширения будущей подписки. В текущей версии нет формы, запросов, сбора или хранения контактов. Перед реализацией потребуются реальный провайдер, обработчик и согласие на подписку. Изменение флага само по себе форму не создаёт.

## Дизайн и доступность

Сохранены чёрно-бело-красная палитра, локальные шрифты и индустриальное помещение `assets/warehouse.png` (атмосферная иллюстрация, не фото артистов или площадки). Карточки поддерживают горизонтальную прокрутку, кнопки и клавиши ←/→. Hover применяется для точного указателя; движения и переходы отключаются при `prefers-reduced-motion`. Новые разделы переходят в одну колонку на мобильных устройствах. Без JavaScript остаются контент, якоря и честные отключённые кнопки.

## Проверка и выпуск

Проверены синтаксис обоих JS-файлов, инициализация полного скрипта с DOM-заглушками, меню, таймер до/во время/после события, прокрутка семи карточек, пустая/неверная/заполненная конфигурация ссылок и безопасный вывод категорий. Проверены порядок артистов, уникальность ID и цели якорей. DOM-заглушки не заменяют реальный layout.

Настоящий браузер недоступен в рабочей среде: перед утверждением нужна визуальная проверка iPhone/Safari и компьютера, включая scroll-snap и длинные будущие названия категорий.

Изменения подготовлены только в `codex/parlador-phase-3-ticketing`, созданной от `main`. Workflow и настройки публикации не добавлены. Merge и публикация выполняются только после разрешения владельца.


## Ценовые этапы

Над сеткой расположен слоган BUY EARLY. PAY LESS. Отображаемые даты сокращены без года, времени и часового пояса. Внутренние границы и Europe/Moscow сохранены.

| Этап | Московское время | Цена |
| --- | --- | --- |
| 1 НЕДЕЛЯ | 21–27 ноября | 1 700 ₽ |
| 2 НЕДЕЛЯ | 28 ноября – 4 декабря | 1 900 ₽ |
| 3 НЕДЕЛЯ | 5–11 декабря | 2 300 ₽ |
| 4 НЕДЕЛЯ | 12–18 декабря | 2 500 ₽ |
| НА ВХОДЕ | 19 декабря | 2 700 ₽ |

Все начала этапов — в 00:00 Europe/Moscow. Начало включительно, конец исключительно. НА ВХОДЕ заканчивается в подтверждённое время завершения события. Покупка непосредственно на входе возможна только при наличии свободных мест; доступность зависит от вместимости площадки и решения организаторов. Онлайн-покупка этого этапа всегда отключена.

До 21 ноября — COMING SOON и шкала будущих цен. После окончания события — SALES STATUS TO BE ANNOUNCED без действующей цены. Открытая страница сверяет этап каждую секунду, а также при возвращении на вкладку, восстановлении страницы и получении фокуса. Фоновые браузерные таймеры могут приостанавливаться; при возврате состояние пересчитывается.

Клиентские часы служат только для информационного отображения. Они могут быть ошибочны: окончательные цена и доступность определяются билетной платформой. Сайт не рассчитывает сумму покупки и не собирает платёжные данные.

## Проверить все даты без ожидания

Запустите из корня репозитория:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Откройте локальные адреса (параметр влияет только на билеты):

- До начала: http://127.0.0.1:8000/?ticketPreview=2026-11-20T12:00:00%2B03:00#tickets
- 1 700 ₽: http://127.0.0.1:8000/?ticketPreview=2026-11-21T00:00:00%2B03:00#tickets
- 1 900 ₽: http://127.0.0.1:8000/?ticketPreview=2026-11-28T00:00:00%2B03:00#tickets
- 2 300 ₽: http://127.0.0.1:8000/?ticketPreview=2026-12-05T00:00:00%2B03:00#tickets
- 2 500 ₽: http://127.0.0.1:8000/?ticketPreview=2026-12-12T00:00:00%2B03:00#tickets
- НА ВХОДЕ: http://127.0.0.1:8000/?ticketPreview=2026-12-19T00:00:00%2B03:00#tickets
- После события: http://127.0.0.1:8000/?ticketPreview=2026-12-20T06:00:00%2B03:00#tickets

Для перехода на открытой странице задайте `ticketPreview=2026-11-27T23:59:58%2B03:00`: через две секунды этап сменится с 1 700 на 1 900 ₽. Аналогично можно проверить остальные границы. Тестовые часы продолжают идти, отображается LOCAL PREVIEW, покупка отключается. На публичном хосте параметр игнорируется. Удалите параметр, чтобы вернуться к обычному времени. Системное время Mac менять не нужно.

Автоматические проверки без зависимостей:

```sh
node tests/ticket-pricing.test.cjs
node tests/site-smoke.cjs
TZ=Pacific/Honolulu node tests/ticket-pricing.test.cjs
TZ=Asia/Tokyo node tests/ticket-pricing.test.cjs
```

Тесты проверяют все границы с точностью до миллисекунды, обновление открытой страницы, ограничения покупки, локальную симуляцию и игнорирование её на публичном хосте. Smoke-проверка запускает все скрипты с DOM-заглушками, меню, таймер и прокрутку. Браузерная визуальная проверка недоступна: мобильная сетка проверена по CSS (5 колонок на компьютере, 2 до 820 px, 1 до 360 px); реальный iPhone/Safari остаётся проверить перед утверждением.
