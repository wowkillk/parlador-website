# PARLADOR — Phase 2

Статический сайт, совместимый с GitHub Pages. Сборка и сервер не требуются: откройте `index.html` или используйте статический сервер. Ресурсы и ссылки относительные, поэтому сайт работает и в подкаталоге репозитория.

Сохранены семь артистов и их порядок: DJ KALASHNIKOV, DANJAMIN, M.E.G, FRDM, ACID BOSS, Девиантный Диалект, DJ ALWEN. Карточки остаются контентом: без биографий, жанров, фотографий, музыкальных ссылок, модальных окон и фиктивных действий. `data-artist-id` задаёт стабильные ключи для будущих профилей; `artistProfiles` зарезервирован в конфигурации, UI профилей пока не создаётся.

Подтверждённое время события не изменено: 19 декабря 2026, 22:00 МСК — 20 декабря, 06:00 МСК. Расписание выступлений отдельных артистов не добавлено.

## Настройка билетов и Telegram

Все публичные настройки находятся в `site-config.js`, который загружается перед `script.js`. Не храните здесь секреты или персональные данные.

- `tickets.platformUrl: null`: TICKETS показывает COMING SOON, BUY TICKET отключена. Для открытия продаж укажите проверенную HTTPS-ссылку реальной билетной платформы. Покупка откроется на этой платформе в новой вкладке. Сайт не принимает платежи.
- `tickets.categories: []`: после подтверждения категорий добавьте объекты `{ name, priceLabel }` с настоящими названиями и ценами. Они отображаются только при наличии корректной ссылки платформы. Текст вставляется через `textContent`.
- `community.telegramUrl: null`: JOIN TELEGRAM отключена. Укажите подтверждённую HTTPS-ссылку канала на `t.me` или `telegram.me`. Пока ссылки нет, переходов нет.
- Неверные, относительные, HTTP- и `javascript:`-ссылки не активируют кнопки. Код проверяет формат URL; подлинность платформы и канала необходимо подтвердить владельцу перед заполнением конфигурации.
- `newsletter: { enabled: false, provider: null }` — точка расширения будущей подписки. В текущей версии нет формы, запросов, сбора или хранения контактов. Перед реализацией потребуются реальный провайдер, обработчик и согласие на подписку. Изменение флага само по себе форму не создаёт.

## Дизайн и доступность

Сохранены чёрно-бело-красная палитра, локальные шрифты и индустриальное помещение `assets/warehouse.png` (атмосферная иллюстрация, не фото артистов или площадки). Карточки поддерживают горизонтальную прокрутку, кнопки и клавиши ←/→. Hover применяется для точного указателя; движения и переходы отключаются при `prefers-reduced-motion`. Новые разделы переходят в одну колонку на мобильных устройствах. Без JavaScript остаются контент, якоря и честные отключённые кнопки.

## Проверка и выпуск

Проверены синтаксис обоих JS-файлов, инициализация полного скрипта с DOM-заглушками, меню, таймер до/во время/после события, прокрутка семи карточек, пустая/неверная/заполненная конфигурация ссылок и безопасный вывод категорий. Проверены порядок артистов, уникальность ID и цели якорей. DOM-заглушки не заменяют реальный layout.

Настоящий браузер недоступен в рабочей среде: перед утверждением нужна визуальная проверка iPhone/Safari и компьютера, включая scroll-snap и длинные будущие названия категорий.

Изменения подготовлены только в `codex/parlador-phase-2`, созданной от `main`. Workflow и настройки публикации не добавлены. Merge и публикация выполняются только после разрешения владельца.
