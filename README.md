# PARLADOR

Откройте index.html в современном браузере. Установка зависимостей и сборка не нужны. Для публикации загрузите все файлы на статический хостинг.

Событие: 19 декабря 2026, 22:00 МСК — 20 декабря, 06:00 МСК. Fabula, Москва.

Билеты: демонстрационный диалог без цен и ссылок. Фон: оригинальная SVG-иллюстрация. Шрифты и лицензии включены в assets/.

Проверка: синтаксис JavaScript и CSS, сценарии таймера до/после начала, мобильное меню и Escape, демо билетов и возврат фокуса, скачивание календаря, локальные ресурсы и якоря. Автоматические сценарии выполнены в jsdom. Визуальная проверка в настоящем браузере недоступна в текущей среде.
